# 2026-09-24 smoke run

This is a small, inspectable run log for the redesign, not a reliability
benchmark. It covers the schema-1 / Ship-0.4.0 receipt contract after the
historical-evidence and malformed-input hardening pass. Commands were run from
a clean checkout of the working tree where possible; each model arm used a
fresh temporary repository.

## Commands

```text
./scripts/validate.sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
./evals/context-cost.sh skills
MODEL=claude-opus-5 ./evals/run.sh ship 04-no-asks
MODEL=claude-opus-5 ./evals/run.sh ship 02-whatsapp-thread

python3 evals/result-bundle.py export --runs evals/runs --out evals/results/2026-09-24-smoke --date 2026-09-24
python3 evals/result-bundle.py verify --bundle evals/results/2026-09-24-smoke
```

The model runs were single trials. Host permission prompts were allowed to be
honest: when a model could not run the checker, the resulting state was checked
again externally. The generated working directories are ignored; a compact
copy of the selected states, replies, validation, and evidence-mode output is kept
in the adjacent result bundle.
